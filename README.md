# Тренировки — Зарядка (PWA)

Личное офлайн-приложение для тренировок в зале «Зарядка» на Берзарина.

## Запуск локально

```
python -m http.server 8080
```
Открыть http://localhost:8080. Тесты логики: `npm test` (нужен Node 20+).

## Установка на iPhone

1. Открыть адрес приложения в **Safari**.
2. «Поделиться» → «На экран Домой».
3. Запускать с иконки — приложение работает без интернета.

## Копия данных

iOS может очищать данные неактивных приложений. Раз в пару недель делайте
«Данные → Экспорт» и сохраняйте файл (например, в «Файлы»). «Импорт» вернёт веса и историю.
