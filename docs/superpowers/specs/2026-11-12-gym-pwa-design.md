# Gym PWA — дизайн (спецификация)

Дата: 2026-11-12. Статус: черновик на проверку пользователем.

## 1. Цель и контекст

Личное PWA для тренировок в зале «Зарядка» (ул. Берзарина, 19к1, Москва) на iPhone (возможно iPad). Заменяет исходный сайт, сделанный в Gemini и встроенный в Google Sites.

Пользователь: средняя подготовка, вес ~72 кг, ходит Пн/Ср/Пт в обед, 30–40 минут на тренировку, иногда 2 раза в неделю. Пресс на каждой тренировке.

Критерии успеха:
1. Ставится на экран «Домой» на iPhone и работает полностью офлайн.
2. Любое упражнение можно заменить на подходящее; замена учитывает мышцу и «где делать», чтобы не бегать по залу.
3. Техника понятна без интернета: собственные схемы (SVG) и короткий текст, без внешних ссылок и гифок.
4. Рабочие веса, прогрессия и история не теряются (экспорт/импорт).
5. Тренажёры из исходной программы считаются проверенными; добавочные помечены «проверить в зале», и их можно скрыть кнопкой «нет в зале».

Вне рамок (YAGNI): аккаунты и облако, карта расположения тренажёров, видео, соцфункции, push-уведомления, распознавание фото.

## 2. Исходная программа (данные для переноса)

Источник: https://sites.google.com/view/berzarina/full-page-embed. Копия в заметках сессии: `source-site-findings.md`. Оборудование — SHUA. 3 дня, по 3 суперсета (антагонистические пары), 3 подхода, отдых 90/90/60 с.

- А (Пн): жим от груди сидя 42.5/5/12 + вертикальная тяга 45/5/12; жим ногами 100/10/12 + сгибание ног сидя 35/5/12; махи гантелями в стороны 8/1/15 + скручивания на наклонной скамье 0/2.5/15.
- Б (Ср): горизонтальная тяга с упором в грудь 45/5/12 + жим на плечи сидя 30/5/12; сгибание ног лёжа 35/5/12 + разгибание ног сидя 40/5/12; трицепс на канате 22.5/2.5/15 + подъём ног в вертикальном тренажёре 0/2/15.
- В (Пт): жим гантелей на наклонной 18/2/12 + подтягивания в гравитроне 20/−2.5/12; «бабочка» 35/5/15 + гиперэкстензия 10/5/15; бицепс Скотт 25/2.5/12 + подъём прямых ног + «велосипед» 0/0/15.

(формат: старт кг / шаг кг / целевые повторы). Эти 18 упражнений — база, `verified: true`.

Известная проблема: в пятницу пресс идёт на двух разных станциях (вертикальный тренажёр и скамья/коврик). Новая программа ставит пресс одним упражнением на одной станции.

## 3. Архитектура

Чистый HTML/CSS/JS, ES-модули, без сборки. Каталог `gym-pwa/` (kids-draw не трогаем).

```
gym-pwa/
  index.html, style.css, manifest.webmanifest, sw.js, icons/
  js/
    data/exercises.js     # каталог упражнений
    data/program.js       # шаблон дней А/Б/В (слоты)
    engine/progression.js # вес/повторы -> следующий вес
    engine/swap.js        # подбор замен
    engine/plan.js        # сборка тренировки из слотов, очередь А->Б->В
    store.js              # localStorage + экспорт/импорт JSON
    diagrams.js           # SVG-схемы техники
    ui/*.js               # экраны
  tests/*.test.js         # node:test
```

Границы: `engine/*` и `data/*` не трогают DOM и localStorage (чистые функции, легко тестировать); `store.js` — единственное место работы с localStorage; `ui/*` читает состояние из `store` и вызывает `engine`.

## 4. Модель данных

Упражнение:
```
{ id, nameRu, primary: 'chest'|'back'|'legs_quad'|'legs_ham'|'shoulders'|'biceps'|'triceps'|'abs'|'lower_back'|'glutes',
  secondary: [...], station: 'machine'|'cable'|'bench'|'mat'|'dumbbell'|'bar'|'captain',
  start, step, reps, settingLabel, tempo, steps: [..3 строки], mistakes: [..],
  diagram: 'id', verified: boolean }
```

Шаблон дня (слоты): `{ day:'A', slots:[ { id, superset:1, role:'push', primary:'chest', defaultEx:'chest_press', rest:90, sets:3, repsLabel:'10–12' }, ... ] }`.

Состояние (localStorage `gympwa.v1`):
```
{ version:1, queue: ['A','B','C'], nextIndex, daysPerWeek: 3|2,
  hidden: [exId], slotOverrides: { 'A_1A': exId },
  weights: { exId: { weight, failStreak } },
  log: [ { date, day, items:[ { exId, sets:[{w,reps,done}] } ] } ],
  lastBackup }
```

## 5. Логика

**Очередь тренировок.** Тренировки идут циклом А→Б→В→А независимо от дня недели; на главном экране «Следующая: Б». Так режим «2 раза в неделю» автоматически покрывает все группы за ~1,5 недели. Можно вручную выбрать любой день.

**Прогрессия** (как в исходнике): если все подходы выполнены и повторы ≥ цели — следующий вес = вес + шаг. Не выполнено — вес тот же, `failStreak++`; при `failStreak ≥ 2` вес снижается на шаг и `failStreak=0`. Для гравитрона шаг отрицательный (меньше помощи). Вес собственного тела (0) растёт отягощением по шагу. Пользователь всегда может изменить вес вручную.

**Замена упражнения.** Кандидаты из каталога, кроме скрытых и уже стоящих в этом дне. Сортировка: (1) та же `primary`; (2) та же `station`, что у соседа по суперсету (минимум беготни); (3) `verified` выше непроверенных; (4) тот же тип нагрузки (push/pull) для сохранения антагонистической пары. Показываем до 6 вариантов. Кнопка «нет в зале» на кандидате скрывает упражнение навсегда (`hidden`); в «Зал» его можно вернуть.

**Пресс.** В каждом дне ровно один слот `abs`. Для слота abs кандидаты ранжируются по `station`, совпадающей с соседом по суперсету; если совпадения нет — показываем это пользователю («пресс на другой станции»), а не молчим.

**Генерация.** «Перегенерировать день» заменяет слоты на лучшие варианты из каталога с теми же правилами (по умолчанию — shuffle среди verified; непроверенные только если включено в «Зал»). Минимальный объём: пересобрать дефолт по слотам; без собственного ИИ.

## 6. Каталог (v1)

Проверенные: 18 упражнений из раздела 2. Предложения для проверки (`verified:false`, пользователь отмечает «есть/нет»): жим гантелей лёжа, тренажёр жима на наклонной, кроссовер, тяга нижнего блока, тяга гантели одной рукой, пуловер на блоке, гоблет-присед, присед в Смите, разведение/сведение бёдер, подъём на носки, ягодичный мостик, обратные разведения на «бабочке» (задняя дельта), махи на блоке, жим гантелей на плечи, сгибание на бицепс на блоке, «молот», отжимания на брусьях в гравитроне, французский жим, планка, скручивания на коврике, кросс-кранчи на блоке, подъём коленей в упоре, русский твист. Точный список и текст техники — в плане реализации.

## 7. Экраны

- **Сегодня:** день, суперсеты, подходы (вес/повторы/«готово»), таймер отдыха (авто-старт после подхода, +15 с, звук/вибрация), кнопка «Завершить» → прогрессия.
- **Упражнение:** схема SVG, 3 шага техники, типичные ошибки, настройка тренажёра, «Заменить».
- **Замена:** список кандидатов с пометкой станции, «✓ проверено» / «проверить в зале», «нет в зале».
- **Неделя/режим:** 3 или 2 дня, очередь, ручной выбор дня.
- **Зал:** список упражнений с переключателями «есть / нет».
- **История и данные:** журнал, графики весов (простые SVG), экспорт/импорт.

UI: тёмная тема, крупные цели нажатия (≥44 px), safe-area, без hover, `viewport-fit=cover`, `apple-mobile-web-app-capable`, иконка 180×180 (apple-touch-icon).

## 8. Схемы техники

Для каждого упражнения — самописная SVG: схематичный контурный человек в двух позах (старт/конец) и стрелка движения, плюс подпись «где расположены руки/спина». Генерируются из параметров (углы суставов) функцией в `diagrams.js`, чтобы не рисовать 40 картинок вручную. Для упражнений с тренажёром рисуется силуэт тренажёра (сиденье, спинка, рукоять) в упрощённом виде. Никаких внешних изображений и ссылок.

## 9. Офлайн и данные

- `sw.js`: precache всех файлов приложения (cache-first), имя кэша содержит версию; при обновлении старый кэш удаляется.
- `manifest.webmanifest`: `display: standalone`, `start_url` и `scope` относительные (для GitHub Pages в подпапке).
- Экспорт: JSON-файл через `navigator.share` (iOS) или скачивание; импорт: выбор файла, проверка `version` и структуры, предупреждение о замене данных.
- Напоминание о копии, если `lastBackup` старше 14 дней.
- `navigator.storage.persist()` запрашивается при первом запуске.

## 10. Тестирование

node:test без внешних зависимостей: прогрессия (рост, провалы, гравитрон), замены (ранжирование, исключение скрытых, пресс), очередь, импорт/экспорт (валидация, миграция версии), целостность каталога (уникальные id, схема существует, слоты ссылаются на существующие упражнения). Ручная проверка в браузере на размере iPhone; офлайн — через DevTools.

## 11. Публикация

GitHub Pages, аккаунт Grove08, отдельный новый репозиторий. Публикация и `git push` — только после явного подтверждения пользователя. Установка на iPhone: Safari → «Поделиться» → «На экран Домой».

## 12. Риски и допущения

- Список тренажёров не подтверждён фото; база = исходная программа (в зале была), остальное помечено «проверить». Фото добавятся позже и могут обновить каталог.
- iOS может чистить данные неактивного PWA — защита: persist + экспорт + напоминание.
- Конкретные стартовые веса взяты из исходной программы; приложение их подстраивает прогрессией.
