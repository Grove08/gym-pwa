# Gym PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Офлайн-PWA для iPhone с программой тренировок зала «Зарядка», заменой упражнений, схемами техники и сохранением весов с экспортом.

**Architecture:** Чистый HTML/CSS/JS с ES-модулями, без сборки. Слой `data/` и `engine/` — чистые функции без DOM и localStorage; `store.js` — единственная точка работы с localStorage; `ui/` читает store и вызывает engine. Service worker даёт офлайн.

**Tech Stack:** HTML/CSS/JS (ES modules), service worker, `node:test` (Node ≥ 20, без зависимостей), GitHub Pages.

**Spec:** `gym-pwa/docs/superpowers/specs/2026-11-12-gym-pwa-design.md`

## Global Constraints

- Все пути относительно `gym-pwa/`; файлы kids-draw не трогать.
- Никаких внешних ресурсов (CDN, шрифты, картинки, ссылки на видео): всё локально.
- Весь текст интерфейса — на русском.
- Пути в `manifest`/`sw.js`/`index.html` только относительные (GitHub Pages в подпапке).
- Ключ состояния localStorage: `gympwa.v1`, поле `version: 1`.
- Тесты: `node --test tests/` (из `gym-pwa/`), логика в `data/` и `engine/` не импортирует `document`/`window`/`localStorage`.
- Публикация и `git push` — только после явного подтверждения пользователя.
- Прогрессия: все подходы `done` и `reps >= target` → `weight + step`; иначе `failStreak+1`; при `failStreak >= 2` → `weight - step`, `failStreak = 0`.
- Отдых по умолчанию 90/90/60 с (по суперсетам), 3 подхода.
- Тёмная тема, цели нажатия ≥ 44 px, `viewport-fit=cover`.

## Review Focus

1. Импорт повреждённого/чужого/старой версии JSON → понятная ошибка, текущие данные не затираются (Task 6).
2. Для слота не осталось кандидатов (все скрыты «нет в зале») → пустой список с пояснением, а не падение (Task 5).
3. localStorage недоступен или переполнен (приватный режим) → приложение работает в памяти и показывает предупреждение (Task 6).
4. «Завершить» с недоделанными подходами или повторами 0 → прогрессия не повышает вес, лог не ломается (Task 4).
5. Гравитрон (отрицательный шаг) и 0-кг упражнения: вес не уходит ниже 0 (Task 4).
